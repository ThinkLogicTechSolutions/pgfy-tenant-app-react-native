# Asset credits

All assets are free for commercial use. Swap remote URLs for bundled local files in
`src/data/images.ts` if you need a fully offline build.

## Brand
- `logo-mark.png` (navy) — provided by the project owner. App icon, adaptive icon, splash and
  favicon are derived from it via ImageMagick. Navy `#01264E` extracted from the logo.

## Illustrations
- Onboarding scenes, empty states and the in-app brand glyph are **original SVGs** in
  `src/components/illustrations/`, colored from the project theme. No third-party files bundled.
