# Firebase & FCM — PGfy Tenant

**Package / bundle id:** `in.pgfy.tenant` (Android `package` + iOS `bundleIdentifier`)

This app uses [`@react-native-firebase`](https://rnfirebase.io) for Firebase Cloud
Messaging (FCM). `android/` and `ios/` are generated by `expo prebuild` (Continuous
Native Generation), so all native wiring lives in `app.json` config + plugins.

## What's wired up

- **Deps:** `@react-native-firebase/app`, `@react-native-firebase/messaging`, `expo-build-properties`.
- **app.json plugins:** `@react-native-firebase/app`, `@react-native-firebase/messaging`,
  and `expo-build-properties` (`ios.useFrameworks: "static"` — required by Firebase iOS pods).
- **Android config:** `expo.android.googleServicesFile: "./google-services.json"` (the file
  lives at the project root; `package_name` inside it is `in.pgfy.tenant`). `POST_NOTIFICATIONS`
  permission added for Android 13+.
- **JS:** `src/lib/messaging.ts` — background handler (module side-effect), permission request,
  token fetch, foreground + token-refresh listeners. Initialised from `app/_layout.tsx`
  via `useMessaging()`. Every call is guarded, so the app is safe before iOS Firebase exists.

## Generate the native projects

```bash
npm install
npx expo prebuild            # or: npx expo prebuild --clean
npm run android              # build + run on a device/emulator
```

Android is ready: on launch, check logs for `[FCM] device token …`, then send a test
message from the Firebase console (Cloud Messaging) to that token.

## Remaining iOS step (Firebase-iOS)

iOS Firebase is intentionally **not** finished yet (no plist provided). FCM is a no-op on
iOS until you complete these steps:

1. Download **GoogleService-Info.plist** for the `in.pgfy.tenant` iOS app from the Firebase
   console and place it at the project root: `tenant-app/GoogleService-Info.plist`.
2. In `app.json`, add under `expo.ios`:
   ```json
   "googleServicesFile": "./GoogleService-Info.plist"
   ```
3. Enable the iOS-only guard in `src/lib/messaging.ts`: change
   `const FCM_SUPPORTED = Platform.OS === 'android';` to `true` (allow iOS).
4. Regenerate and install pods:
   ```bash
   npx expo prebuild -p ios --clean
   cd ios && pod install && cd ..
   npm run ios
   ```
5. In the Apple Developer portal enable **Push Notifications** for the App ID and upload an
   **APNs key** to Firebase (Project Settings → Cloud Messaging).
